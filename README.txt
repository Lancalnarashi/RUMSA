RUMSA 阿爾特萊茵皇家醫學大學網站

開啟方式：
1. 將整個 rumsa-website 資料夾解壓縮。
2. 直接雙擊 index.html 即可在瀏覽器開啟。

檔案：
- index.html：網站內容與結構
- styles.css：視覺樣式與響應式設計
- script.js：手機選單、滾動動畫、學院搜尋與分類功能

修改方式：
- 校名、文案、科系內容可直接在 index.html 編輯。
- 顏色可在 styles.css 最上方的 :root 區塊修改。
- 網站不依賴外部框架或圖片，可離線使用，也可上傳至 GitHub Pages、Netlify 或其他靜態網站服務。
